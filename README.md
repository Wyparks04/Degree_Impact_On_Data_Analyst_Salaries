## 1. Project Setup Instructions

Follow these steps to download, install, and run the project locally.

### Clone the repository
```bash
git clone https://github.com/wyparks04/Degree_Impact_On_Data_Analyst_Salaries.git
cd Degree_Impact_On_Data_Analyst_Salaries

Create a virtual environment
bash
python -m venv venv
Activate the virtual environment
Windows (Git Bash):

bash
source venv/Scripts/activate
Windows (Command Prompt):

bash
venv\Scripts\activate
macOS/Linux:

bash
source venv/bin/activate
Install dependencies
bash
pip install -r requirements.txt
Run the project
Start Jupyter Notebook:

bash
jupyter notebook
Then open the notebook you want to run (e.g., 01_degree_jobs_cleaning.ipynb) and execute the cells.
